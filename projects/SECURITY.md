# Portfolio Lab Security

These repositories contain **defensive educational demonstrations** using synthetic data. All local scripts operate offline using the Python standard library.

- Do not upload actual Terraform plan output, domain account exports, vulnerability exports, passwords, keys, tokens, or personal information.
- Use only machines, cloud subscriptions, and directories you own or have explicit permission to administer.
- Apply a cloud budget and destroy test infrastructure after an authorized exercise.
- Treat sample detection results as educational: they must be verified and reviewed before production action.
- Report a security concern privately rather than committing a real secret to a public Git repository.

There is no active third-party service integration or secret requirement for these projects.
